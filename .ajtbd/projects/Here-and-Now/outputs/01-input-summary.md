# 01. Input summary

- Проект: Here-and-Now
- Источник идеи: `.ajtbd/projects/Here-and-Now/inputs/Описание функций Here-and-Now.docx`
- Дата прогона цепочки: 2026-03-17 14:41
- Гипотеза продукта: геолокационное приложение для быстрых офлайн-встреч по интересам в радиусе 3 км и планируемых встреч в районе.

## Ключевые сигналы из входа

- Цель: живые встречи без долгих переписок, «в 2 клика».
- Механика: карта, карточки встреч, заявка на участие, подтверждение организатором, групповой чат.
- Основной сценарий MVP: спонтанные встречи «здесь и сейчас».
- Дополнительный сценарий: запланированные встречи и районные сообщества.
- Единицы ценности: скорость подбора компании, релевантность интересам, безопасность через профиль и рейтинг.
